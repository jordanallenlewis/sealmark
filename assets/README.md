# Brand assets

Copied unchanged from the official Sealmark logo in `sealmark-site` (`web/app/`, drawn from `web/lib/logo.json`). Not redrawn.

- `logo.svg`: the mark (gold ring and disc, dark rows). One variant: the gold disc reads on light and dark backgrounds.
- `favicon.ico`, `apple-touch-icon.png`: icon sizes.
- `social-preview.png`: 1200x630 card, same as sealmark.dev. To use it as the GitHub social preview: repo Settings > Social preview > Upload (not settable through the API).

Source of truth is `sealmark-site`; update these from there.
